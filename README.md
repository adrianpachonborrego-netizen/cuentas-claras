# Cuentas Claras

Web estática de finanzas personales (calculadoras + guías + plantillas de pago) que mantiene un edificio de agentes de IA. Ver `AGENTES.md`.

- Generar la web: `pip install markdown && python3 build.py` → carpeta `docs/`
- GitHub Pages: Settings → Pages → Branch `main`, carpeta `/docs`
